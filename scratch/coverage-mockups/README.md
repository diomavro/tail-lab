# Coverage network mockups (scratch)

Standalone HTML mockups, sample data only. Open any file in a browser; the three link to each other.

- `client-view.html` – relationship network for one client (bankers ↔ contacts, decision makers, channel/frequency)
- `portfolio-view.html` – all clients: which banker covers which client, decision-maker coverage, key-person risk
- `personal-view.html` – "My coverage": viewing-as picker, private raw notes, shared interaction notes, client news, biggest-moves placeholder

Not part of tail-lab. Lives on this branch only; delete when done.
